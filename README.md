# 🎬 CineMatch - Movie Recommendation System

## Objective

CineMatch is a machine learning-based movie recommendation application that helps users discover movies similar to their interests. The system uses Content-Based Filtering and Cosine Similarity to generate personalized recommendations.

## Features

* Movie Search
* Personalized Recommendations
* Movie Poster Display
* Responsive User Interface
* Machine Learning Recommendation Engine

## Tech Stack

* Python
* Flask
* Pandas
* Scikit-Learn
* HTML
* CSS
* TMDB API

## Machine Learning Technique

The project uses:

* Content-Based Filtering
* CountVectorizer
* Cosine Similarity

## Project Workflow

1. Dataset Preprocessing
2. Feature Extraction
3. Vectorization
4. Similarity Calculation
5. Recommendation Generation
6. Web Application Interface

## Installation

```bash
pip install -r requirements.txt
python model.py
python app.py
```
